### 2. 特斯拉營收淨利毛利數據優勢分析

- 我覺得特斯拉目前他的優勢，在其他的傳統車廠要去追趕的一個前提之下，就是你可以期待，可以保持還滿長的一段時間，我不覺得可以在很快然後讓別人可以去追上他目前所有的一個優勢。
- 我們稍微唸過去：他的營收 1.2 是 81%，那調整後的淨利是 25%，那汽車的毛利在 33% 左右。

### 3. 挖礦金屬生意與庫存天數轉嫁價格

- 再來特斯拉未來可能還會自己介入挖礦的生意，今天講挖礦不是講說用 CPU GPU 或是各種礦卡去挖什麼以太或是比特幣，我們講挖礦是真正的跑去挖這些金屬的礦石。
- 特斯拉他是可以把價格轉嫁出去的，這個我們可以用一個比較簡單數據看，就是他的這個 Goods Inventory 就是他現在的庫存天數。

### 4. Bear Case 2900 Bull Case 5800

- 大家更新新的數字，就是 Bear Case 是 2900，那一般的 case 是 4600，那如果是 Bull Case 是 5800。

### 5. 自動駕駛普及面臨認知挑戰辯論

- 我覺得最大的挑戰並不是技術層面，技術層面可能我相信假以時日然後就是一定可以辦到，但是比較困難的地方應該是在於一般人的認知之下，可能會難以接受這件事情。
- 我認為在接下來的幾年，我們可能會看到更多這樣子的辯論，就是會有很多人試著要去妖魔化這些所謂的自動駕駛，或是像是飛機的自動駕駛我們可能覺得是很合理一個很完美的解方，但大家就講說飛機跟車子不一樣，反正都會有這樣的人都會跟講說他什麼不一樣。

### 6. 特斯拉保險推廣自動駕駛關鍵一環

- 特斯拉保險這塊如果有做起來的話，我相信自動駕駛的普及才可以更有效的去推廣。
- 特斯拉在自動駕駛的努力上，我覺得他最主要的一環就是他的特斯拉保險。
