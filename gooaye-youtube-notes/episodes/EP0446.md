## 章節觀念


### 1. Q1 歷史新高業力引爆回美股日常

- 因為可能本來想說在第一季的時候，跟大家分享自己的績效想說今年有可能會刷歷史新高，因為在 Q1 的時候就打出一個歷史新高的 Q1 表現，那在整年跑完說不定會打出一個超屌的表現，然後沒有想到在第二季就開始整個業力引爆回去了，不管是台股或是美股都是這樣。
- 你要知道這就是市場的一個日常，就是總是會有這種很可怕的狀況出現，但要習慣。

### 2. 台積電財報展望涵蓋 HPC、AI server 與一般伺服器業務

- 好，那我們來聊一下台積電最新財報裡面寫的內容還有一些展望，順便講一下自己的想法。
- HPC 裡面就是包含的像是大家看到 PC、NB，就算了，那 general server 也在裡面，AI server 也在裡面。

### 3. 台積電長期軌跡不受短線股價變化或地緣政治影響

- 反正就是這樣，不要去拿短線、短線股價的變化來講故事，因為這真的很低能。
- 我們來看一下就是台積電它本身自身的業務，然後以及為什麼他們會講出這樣子的話，來推敲一下到底隱含的業界的狀況是怎麼樣。

### 4. 長期大趨勢與地緣政治影響

- 但我認為這家公司它長期的軌跡就是擺在那邊，除非它有遇到一些短線上的影響，不管是地緣政治或是一些天災人禍，不然其實大致上就會長這個樣子。
- 我還是會覺得說這些東西有可能是長期的大趨勢，後面可能還有很多東西可以看到。
