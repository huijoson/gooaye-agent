## 章節觀念


### 1. 資金做 VXX 選擇權期貨對沖

- 隨時手上保著一點資金，那這些資金呢，你可以在下跌的時候，像我們剛剛最前面的進階玩法，拿來做 VXX，或是拿來做選擇權，拿來做期貨做一個對沖。
- 可是我拿一成出來做了空頭的部位的對沖，假設我買的是 VXX，然後用買的超準的話，那我會上漲是五倍，假設整個股災過去我是上漲五倍。

### 2. 高點下跌直接減碼或單純避險做法建議

- 如果說我今天在高點開始下跌的時候，我就直接把我一半的部位砍出去。
- 如果說沒那麼進階的做法，其實就很單純，開始下跌的時候，一般我會建議這樣，就是你開始下跌，或是你開始覺得有點怪怪的時候，這裡都可以。

### 3. Microsoft 跌到兩百塊 Azure 營收不符預期

- 以 Microsoft 的角度來講，回到他最前面提到的減碼的東西，如果說200多塊的 Microsoft 你買得很高興，那跌到200塊的 Microsoft 給你買，為什麼你會覺得好像世界要毀滅，好像它要完蛋，是不是要出什麼大事？
- 很多人現在開始就把理由找到這邊，說因為這個 Azure 的營收成長不符合預期。

### 4. 勝率四五成配合資金控制聯詠創意虧損案例

- 很多人都以為說你要什麼勝率八成才可以在股票賺錢，其實不是，你勝率有個四五成，你資金控制得宜的話，看對的就加，看錯的就慢慢減，也不要一直砍掉，因為有時候你只是可能被洗了一下而已，那它就會有很大的差別。
- 聯詠、創意好像賠了到五十八萬還多，六十萬，因為重壓。
