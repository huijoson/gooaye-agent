## 章節觀念


### 1. 高端圈層日常互動與長輩化過程

- 甚至到後面會發現，我相信大家如果是在地方各種群組有去埋伏，不管是什麼股票群或是自己產業圈的，就會注意到，那種越是高端的圈子，就是他們知道最多東西的，他們越常講的是那種很日常的東西，每天跟你早安晚安什麼的，不會說整天都在交流一些非常產業面的數字之類的東西。
- 但當然我們在長輩化的過程之中，會發現其實每一代都在做加強。

### 2. 台系廠商財報反漲與匯損消化

- 再來就是像大立光的財報開出來之後竟然是反漲，這個對我們來講，也是我可以視為說，說不定市場已經消化完這件事情了。
- 但是如果說我們連續地觀察到一些……就是說以台系廠商來講，大家會盯著一些重點，像一些交換器或一些 Server 的 ODM、OEM，如果說他們也把匯損的成績單開出來，然後都不用去反應的話，那真的可以相當程度地視為說，匯損這件事情可能已經不存在了，我們就視為說市場已經是完全去消化掉這件事情。

### 3. AWS IRHX 伺服器推出與供應鏈機會

- 在 AWS 伺服器有一樣，就是他們最近有蠻多話題的，它推出了一個叫做 IRHX 的東西。
- 於是呢，在像台灣的台系供應鏈，這個就是會是一種機會。

### 4. AI 模型通用性與領域知識差異

- 因為不一定是大家在現在這種 AI 模型已經是難分軒輊的狀況之下，還會想要特別地去開模型來問，就是你可能就會發現我還是在 Google Search Bar 上面去問它就好了。
- 但如果你今天是用在 coding 或者有些特殊應用上的話，各家模型可能因為他們有一些特別的 domain knowledge，他們可以玩出不一樣的東西。
