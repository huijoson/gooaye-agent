## 章節觀念


### 1. 馬斯克模擬論與台灣 MR 晶片公司

- 我突然間好像可以懂馬斯克講的，他說我們搞不好都活在 simulation 裡面，我們搞不好都活在模擬裡面。
- 好，那是禮拜跟我們投資的團隊一起去看的一家在台灣的 MR 公司。

### 2. 每年 4M 晶片需求與台積電上看 2000

- 它現在可能一年大家可能抓個 4M 吧，就是 4 個 Million 顆的晶片，可是問題就是他要的其實是更多的，他是希望有更多更多的晶片。
- 可是在短期內的東西，就是我們去看可能 27 年的一個 Forward PER 去推的話，台積電摸到 2000 我覺得是非常容易的事情。

### 3. 上修 50B CAPEX 與台積電 50B 以上投資

- 我們就是稍微的重用一點，我覺得就是先去假設說可能會開一個 50B 左右的一個 CAPEX，那這就是某種程度上的一種上修了。
- 目前我們看到在台積電這邊，甚至有可能，你在今年會，當然他們可能多時候會在第一季就直接告訴大家，他們全年會怎麼樣，有機會可以看到說 CAPEX 會開到 50 個 B 以上。

### 4. 終端 Edge 設備市場與 pseudo SRAM L3 Cache

- 如果說我們今天是在講華邦店，或是在講說愛普的這種 SRAM-like 的一個 solution，VHM 或是 Cube 的話，它其實是比較偏向是在 Edge Device，就是在終端的東西裡面。
- 時候一個大膽的猜想就是說，台系的一些可能跟 SRAM 相關的，包含說他可能是做這個 pseudo SRAM 的，或者是說他可能是做某種，像那時候跟大家講的華邦，因為他的 Cube，在他的官方網站是直接寫說，這個東西就理論上，他是可以把它作為是 L3 cache 來做使用…
